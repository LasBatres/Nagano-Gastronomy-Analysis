# Nagano-Gastronomy-Analysis
Active project where I investigate the relationship between Nagano's restaurant prices and ratings.

This idea begins with my chef-wife's desire to live a full gastronomic Japan experience combined with JDM preferences, so Nagano is where both interests converge.
Because of funding and transportation limitations, I started to think...
Does there exist a perfect path where we can experience the balance between prices and flavors at each restaurant?
Once I localize the most convenient restaurants for each type of cuisine, how can I go there?

-------------------------------------

## TECHNICAL GOALS
1. Create the pipeline using Tabelog as a basis.
2. Save all useful and available information for the purpose intended for each restaurant.
3. Clean all data for machine and person-reading purposes.

## ANALYSIS GOALS
1. Determine the relationship between prices and ratings.
2. Measure the distance for each restaurant to its closest public transport station.
3. Find the satisfaction function to evaluate each restaurant.
4. Optimize the satisfaction function to find the best places.

-------------------------------------
## TECH STACK
1. **Languages:** Python, Octave.
2. **Python libraries:** Requests, BeautifulSoup, Pandas, NumPy, csv.
